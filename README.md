# 🎬📚 Movies & Books Bot

Telegram бот для управления вашими списками фильмов и книг с отслеживанием прогресса.

## 📋 Описание

Бот помогает организовать ваши списки фильмов и книг, отслеживать прогресс просмотра и чтения, а также случайным образом выбирать что посмотреть или почитать, когда вы не можете определиться с выбором.

## ✨ Функциональность

### 🎯 Основные возможности:

- **🎬 Случайный фильм** - выбор случайного фильма из вашего списка с показом статистики
- **📚 Случайная книга** - выбор случайной книги из вашего списка с показом статистики
- **✅ Отметить прочитанное** - перенос книг и фильмов в списки завершенных
- **✏️ Редактирование списков** - управление вашими списками фильмов и книг
- **📊 Статистика** - отслеживание прогресса по книгам и фильмам

### 📝 Редактирование списков:

- **Добавить один фильм/книгу** - пошаговое добавление отдельных позиций
- **Загрузить список фильмов/книг** - массовое добавление списком (каждая позиция с новой строки)

### ✅ Отслеживание прогресса:

- **Отметить фильм как просмотренный** - перенос из очереди в завершенные
- **Отметить книгу как прочитанную** - перенос из очереди в завершенные
- **Автоматическая статистика** - подсчет количества в очереди и завершенных
- **Умный поиск** - для больших списков доступен поиск по названию

## 🚀 Быстрый старт

### 1. Создание бота

1. Найти [@BotFather](https://t.me/BotFather) в Telegram
2. Отправить команду `/newbot`
3. Следовать инструкциям и получить токен бота

### 2. Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd movies-books-bot

# Установка зависимостей
pip install python-telegram-bot==20.7

# Запуск бота
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
python bot.py
```

### 3. Начало работы

1. Найдите бота в Telegram по имени
2. Нажмите START или отправьте `/start`
3. Используйте кнопки для навигации

## 🎮 Использование

### Главное меню:

- **🎬 Фильмы** - получить случайный фильм со статистикой
- **📚 Книги** - получить случайную книгу со статистикой
- **✅ Отметить прочитанное** - перенести книги/фильмы в завершенные
- **✏️ Редактировать списки** - управление списками

### Меню отметки прочитанного:

- **🎬 Отметить фильм** - выбрать фильм для отметки как просмотренный
- **📚 Отметить книгу** - выбрать книгу для отметки как прочитанной
- **📊 Статистика** - посмотреть подробную статистику прогресса
- **🔙 Назад** - возврат в главное меню

### Меню редактирования:

- **📝 Добавить один фильм/книгу** - добавление одной позиции
- **📋 Загрузить список фильмов/книг** - добавление списка
- **🔙 Назад** - возврат в главное меню

## 💡 Примеры использования

### Добавление одного фильма:

1. Нажмите "✏️ Редактировать списки"
2. Выберите "📝 Добавить один фильм"
3. Введите название: "Интерстеллар"
4. Получите подтверждение с обновленной статистикой

### Отметка книги как прочитанной:

1. Нажмите "✅ Отметить прочитанное"
2. Выберите "📚 Отметить книгу"
3. Введите название книги из списка
4. Получите подтверждение с обновленной статистикой

### Массовое добавление книг:

1. Нажмите "✏️ Редактировать списки"
2. Выберите "📋 Загрузить список книг"
3. Введите список:

```
Взрослые дети эмоционально незрелых родителей
Страх близости Илсе Санд
Эмоциональный интеллект
Терапия настроения Д. Бернс
```

4. Получите подтверждение с количеством добавленных книг

### Просмотр статистики:

1. Нажмите "✅ Отметить прочитанное"
2. Выберите "📊 Статистика"
3. Увидите:
   - Количество фильмов/книг в очереди
   - Количество завершенных
   - Общий прогресс

## ⚙️ Технические детали

### Зависимости:

- `python-telegram-bot==20.7` - работа с Telegram API
- `Python 3.7+` - версия Python

### Хранение данных:

- Данные хранятся в оперативной памяти
- При перезапуске бота списки очищаются
- Для постоянного хранения рекомендуется добавить базу данных

### Особенности:

- **Автоматическая статистика** - обновляется после каждого действия
- **Умные списки** - для больших списков используется поиск и пагинация
- **Валидация ввода** - проверка существования элементов при отметке
- **User-friendly интерфейс** - интуитивная навигация по кнопкам

## 🔧 Разработка

### Структура проекта:

```
movies-books-bot/
├── bot.py          # основной код бота
├── requirements.txt # зависимости
├── deploy.sh       # скрипт деплоя
```

### Ключевые функции:

- `get_user_stats()` - расчет статистики пользователя
- `mark_book() / mark_movie()` - отметка завершенных items
- `process_marking()` - обработка ввода при отметке
- `show_stats()` - отображение подробной статистики

## 🚀 Автоматический деплой

Бот поддерживает автоматический деплой через GitHub Actions:

- Автоматическое тестирование при push
- Деплой на сервер при успешных тестах
- Автоматический перезапуск сервиса

## 📝 Примечания

- ⚠️ **Токен бота должен храниться в секрете**
- 💾 Для продакшн-использования рекомендуется добавить базу данных
- 🔄 При перезапуске бота все данные теряются
- 📊 Статистика обновляется в реальном времени
- 🔍 Для списков >50 элементов доступен поиск по названию
